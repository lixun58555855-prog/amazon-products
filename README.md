# 亚马逊商品采集助手 (Amazon Product Saver) - Chrome 扩展

一款基于 Chrome Manifest V3 标准构建的轻量级、开箱即用扩展。在浏览亚马逊各国家站点（美、英、德、日、法等）商品页面时，支持一键将核心商品信息保存到本地产品库（离线存储），提供精美看板管理、多维筛选检索与 CSV/Excel 导出。

## 目录结构

```text
亚马逊产品库/
├── manifest.json       # 扩展配置文件（Manifest V3 标准规范）
├── background.js       # 后台 Service Worker（右键菜单注册、通信与存储）
├── content.js          # 内容注入脚本（DOM核心字段解析提取、悬浮按钮、Toast提示）
├── popup.html          # 弹出窗口 / 管理界面 HTML 结构
├── popup.css           # 现代化深色拟态 UI 样式表
├── popup.js            # 管理界面核心交互逻辑（搜索、筛选、排序、CSV导出）
├── dashboard.html      # 独立全屏看板页面（大屏沉浸式管理）
└── icons/              # 扩展图标资源目录
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

## 在 Chrome 浏览器中加载与测试步骤

1. 打开 Google Chrome 浏览器，在地址栏输入 `chrome://extensions/` 并按回车进入“扩展程序”管理页。
2. 在右上角开启 **“开发者模式” (Developer mode)** 开关。
3. 点击左上角出现的 **“加载已解压的扩展程序” (Load unpacked)** 按钮。
4. 在弹出的文件夹选择框中，选中当前项目根目录：
   `C:\Users\cc271\Documents\ChatGPT\亚马逊产品库`
5. 加载完成后，在浏览器右上角扩展拼图图标中找到 **“亚马逊商品采集助手”**，点击固定（Pin）到工具栏。

## 使用方法

### 1. 右键菜单一键采集
- 在任意亚马逊（如 `amazon.com`、`amazon.co.jp`、`amazon.co.uk` 等）商品详情页面中，鼠标右键点击任意位置。
- 选择上下文菜单中的 **“📥 添加到本地产品库”**。
- 页面右下角将弹出轻量提示框：“🎉 采集成功已入库！”（若已入库则自动同步更新最新价格与时间）。

### 2. 页面悬浮便捷按钮采集
- 页面右侧常驻 **“存入产品库”** 便捷浮钮，浏览时无需打开右键菜单，单触即存。

### 3. 产品库管理台 (Popup & Dashboard)
- 点击浏览器工具栏的插件图标即可唤起管理弹窗。
- **网格 / 列表视图切换**：支持卡片视觉流与紧凑表格视图自由切换。
- **采集当前页**：顶部点击“采集当前页”，无需离开插件即可入库。
- **全屏独立看板**：点击右上角外链图标，可在独立大标签页中沉浸式管理海量商品。
- **多维筛选与排序**：支持按站点过滤、按入库时间/价格升降序、关键词实时模糊检索。
- **导出 CSV / Excel**：点击“导出 CSV”，自动生成带 UTF-8 BOM 的表格文件，Excel 打开绝不乱码。
